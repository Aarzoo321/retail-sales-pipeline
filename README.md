# Retail Sales Data Engineering Pipeline

## Overview
An end-to-end data engineering pipeline that processes retail sales data,
performs data cleaning and validation, loads data into MySQL, and provides
REST APIs using FastAPI.

## Tech Stack
- Python
- Pandas
- MySQL
- SQLAlchemy
- FastAPI
- Pytest
- Git & GitHub

## Pipeline
1. Extract data from Excel files
2. Profile data quality
3. Clean and transform data
4. Validate processed data
5. Load data into MySQL
6. Create analytical tables
7. Expose data through REST APIs

## Project Structure
- `pipeline/` - ETL scripts
- `api/` - FastAPI application
- `sql/` - SQL scripts
- `tests/` - Automated tests
- `data/reference/` - Reference datasets
- `docs/` - Data quality reports

## Features
- Data cleaning and transformation
- Data quality validation
- MySQL data warehouse
- REST API endpoints
- Automated testing
